# Workshop 1: R for Reproducible Data Analysis

## Overview

This workshop introduces the foundations of reproducible data analysis in R. Students learn how to organize a research project, import and clean data, handle missing values, transform variables, inspect distributions, and effectively visualize findings.

## Learning objectives

- Understand a reproducible R project workflow
- Import and clean structured data in R
- Reshape datasets into tidy form
- Work with dates, missing values, and factor variables
- Produce descriptive statistics and professional visualizations
- Document code and analysis decisions clearly

## Dataset

Country-year dataset inspired by Gapminder/WDI-style indicators.

## Typical workflow

- create or update an R project
- read data into R
- inspect variables and missingness
- clean strings and dates
- reshape from wide to long form
- calculate summary statistics
- create graphs with `ggplot2`
- write clean, reproducible scripts
