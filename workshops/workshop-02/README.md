# Workshop 2: Regression Diagnostics & Multivariate Methods in R

## Overview

This workshop extends the data analysis foundation into model checking, multivariate methods, and dimension reduction. Students learn how to diagnose OLS violations, adjust standard errors, and use factor analysis or principal component approaches for structured data.

## Learning objectives

- Diagnose OLS assumptions and specification problems
- Estimate robust standard errors and assess VIF
- Apply variable transformations and model refinement
- Run PCA and exploratory factor analysis
- Interpret scree plots, loadings, and component scores
- Carry out optional clustering exercises

## Datasets

- Country-context dataset (WDI + WGI + ILOSTAT)
- Global Findex dataset for PCA/factor work
- Polish Companies Bankruptcy dataset as optional clustering exercise

## Typical workflow

- estimate baseline and transformed regressions
- test heteroskedasticity and linearity
- assess multicollinearity and leverage
- estimate robust or corrected inference
- conduct PCA/EFA and interpret outputs
- compare clustering structure when appropriate
