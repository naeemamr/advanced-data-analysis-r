# Workshop 3: Panel & Time-Series Analysis in R

## Overview

This workshop introduces students to two major applied econometric frameworks: panel data methods and time-series analysis. The module combines methodological rigor with applied coding examples in R using macroeconomic and development datasets.

## Learning objectives

- Declare and model panel data
- Estimate pooled, fixed-effects, and random-effects models
- Use clustered standard errors
- Explore stationarity and serial dependence in time series
- Estimate ARIMA and ARDL-type models
- Demonstrate VAR and impulse response analysis when time permits

## Datasets

- WDI/Gapminder country-year panel
- IMF/FRED/CBE macroeconomic time series

## Typical workflow

- build panel data objects with fixed and time dimensions
- compare pooled, FE, and RE models
- diagnose serial correlation and clustering
- generate time series objects and test stationarity
- inspect ACF/PACF and estimate ARIMA/ARDL models
- optionally estimate VAR and IRF models
