# Workshop 4: Quantitative Text Analysis in R

## Overview

This workshop introduces students to quantitative text analysis using R. It focuses on text preprocessing, corpus construction, term-document matrices, dictionary-based scoring, and basic supervised evaluation of classifiers.

## Learning objectives

- Build a corpus and tokenize texts in R
- Generate document-feature matrices and TF-IDF scores
- Use quanteda-style workflows for textual analysis
- Evaluate dictionary-based measures
- Conduct basic classification evaluation
- Explore optional topic modeling or embedding methods

## Dataset

Existing BIS central-bank speeches corpus or a selected pre-prepared subset.

## Typical workflow

- import source text files or CSV corpus data
- clean and tokenize text
- build DFMs and weighted term matrices
- estimate document tone or dictionary scores
- compare findings across speeches or periods
- test basic classification metrics if classification tasks are included
